# Visual Style Guide

## Color Palette
- Primary: #0052FF
- Secondary: #1A1A2E
- Accent: #00D4AA
- Background: #FFFFFF
- Surface: #F5F5F7
- Text Primary: #1A1A2E
- Text Secondary: #6B7280
- Error: #DC2626
- Success: #059669

## Typography
- Headings: Inter, 600 weight
- Body: Inter, 400 weight
- Data / Code: JetBrains Mono, 400 weight
- Base size: 16px
- Scale: 1.25 (major third)

## Spacing
- Base unit: 4px
- Scale: 4, 8, 12, 16, 24, 32, 48, 64

## Component Preferences
- Buttons: filled primary, outline secondary
- Cards: subtle shadow, 8px border radius
- Navigation: left sidebar (collapsible on mobile)
- Tables: bordered, zebra striping on rows
- Forms: floating labels, inline validation

## Accessibility
- WCAG Level: AA
- Minimum contrast ratio: 4.5:1 (normal text), 3:1 (large text)
- Focus indicators: visible, high contrast
- Keyboard navigation: all interactive elements reachable
